# AttendEase – Student Attendance Management System

## 📌 Project Description

**AttendEase** is a Java-based Student Attendance Management System designed to simplify and organize the process of managing student attendance.

The system allows users to add student details, mark attendance, view attendance records, and calculate attendance percentages. It helps reduce manual effort and provides a simple and structured way to manage attendance information.

This project is developed using **Java** and applies fundamental **Object-Oriented Programming (OOP)** concepts.

---

## ✨ Features

- ➕ Add new students
- 👨‍🎓 Store student details
- ✅ Mark students as Present
- ❌ Mark students as Absent
- 📋 View attendance records
- 🔍 Search for student information
- 📊 Calculate attendance percentage
- 📁 Manage multiple student records
